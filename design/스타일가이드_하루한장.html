하루한장 스타일가이드

흰 캔버스, 짙은 잉크 텍스트, 그리고 단 하나의 강조색 Rausch. Airbnb 디자인 시스템의 따뜻하고 여유로운 문법을 가져와, 지친 사장님이 하루 장사를 30초 안에 기록하고 쉬운 문장으로 돌려받는 화면에 맞게 다듬었습니다.

단일 강조색 그림자 1단계 모든 요소 라운드 8px 기반 간격

1. 디자인 원칙

Airbnb의 시각 원칙을 하루한장의 서비스 장벽(기록 중단, 디지털 사용의 어려움, 분석 결과 오해)에 맞춰 다시 정리했습니다.

01

강조색은 한 화면에 한 번

Rausch는 「기록 저장」처럼 화면의 주 행동 하나에만 씁니다. 화면의 90%는 흰색과 잉크로 채웁니다.

02

글자보다 여백이 위계를 만든다

제목은 22–28px로 차분하게 둡니다. 크게 강조하는 곳은 핵심 지표 숫자 하나뿐입니다.

03

누르기 쉬운 크기

주요 버튼은 48px 이상, 기록 선택 버튼은 72px로 키웁니다. 피곤한 손가락도 한 번에 누를 수 있어야 합니다.

04

둥글고 부드럽게

버튼 8px, 카드 14px, 칩과 검색바는 완전한 알약 모양입니다. 날카로운 모서리를 두지 않습니다.

05

색만으로 말하지 않는다

좋음/보통/나쁨은 초록·빨강 대신 모양(●/○/–)과 글자로 구분합니다. Airbnb가 별점을 잉크색으로 칠하는 것과 같은 절제입니다.

06

단정하지 않는 말투

“비 오는 날 손님이 줄어드는 경향이 있어요”처럼 분석은 참고 정보로 전합니다. 신뢰도 배지를 함께 붙입니다.

2. 컬러

견본을 누르면 HEX 값이 복사됩니다. 공개 웹 기준으로 다크 모드는 두지 않습니다(DESIGN.md 「Canvas」 항목).

Rausch는 한 화면에서 1–2곳만 씁니다. Luxe(#460479)와 Plus(#92174d)는 서브 브랜드 전용 토큰이라 하루한장 기본 화면에서는 쓰지 않습니다. 유료 기능에 별도 정체성이 필요할 때만 검토합니다.

3. 타이포그래피

원본 서체 Airbnb Cereal VF는 라이선스 서체입니다. 그래서 DESIGN.md가 권하는 대체 서체 Inter를 라틴 문자에, 같은 성격의 Pretendard를 한글에 씁니다. 굵기는 500–700 사이로 절제합니다.

ⓘ
하루한장 적용 규칙

사장님 화면의 본문은 16px 아래로 내리지 않습니다(접근성 장벽 대응). 14px 이하는 날짜·출처 같은 보조 정보에만 씁니다. 한글은 word-break: keep-all로 단어 중간에서 줄이 바뀌지 않게 합니다.

5. 엘리베이션

그림자는 평면과 떠 있음 두 단계뿐입니다. 깊이는 그림자를 겹쳐서가 아니라 여백과 둥근 모서리로 만듭니다.

FLAT

본문, 구역, 푸터 등 화면의 95%. 그림자를 쓰지 않습니다.

FLOAT · 유일한 그림자

카드에 마우스를 올렸을 때, 기록 카드, 드롭다운, 배지에 씁니다.

SCRIM · 50%

모달, 날짜 선택, 로그인 창 뒤에 깝니다.

box-shadow: rgba(0,0,0,.02) 0 0 0 1px,
            rgba(0,0,0,.04) 0 2px 6px 0,
            rgba(0,0,0,.1)  0 4px 8px 0;

13. 반응형

Airbnb의 브레이크포인트를 그대로 씁니다. 화면이 좁아지면 행을 다시 배치하지 않고 열 수만 줄입니다.

14. Do / Don't

✓ DoRausch 버튼은 한 화면에 하나만 둡니다.
✕ Don't강조색을 여러 곳에 쓰면 무엇을 눌러야 할지 흐려집니다.
● 좋음○ 보통– 나쁨

✕ Don't신호등 색을 쓰지 않습니다. 팔레트에 없고, 색약 사용자는 구분하기 어렵습니다.
